Supermarket Sales Analysis

Project Overview

This project focuses on analyzing supermarket sales data using SQL and Microsoft Excel.

The objective of the project is to analyze sales data, identify important trends and patterns, and present the findings through an Excel dashboard.

Tools Used

- SQL
- Microsoft Excel
- Excel Dashboard
- Data Analysis

Project Components

SQL Analysis

The SQL analysis contains queries and analysis performed on the supermarket sales data.

Excel Dashboard

An Excel dashboard was created to present the sales analysis in a clear and visual format.

Sales Data

The Excel workbook contains the supermarket sales data used for the analysis.

Dashboard Screenshot

A screenshot of the completed dashboard is included for quick viewing.

Certificate

The SQL course certificate is included as evidence of completed learning.

Files Included

- SQL Analysis PDF
- Excel Dashboard and Supermarket Sales Data
- Dashboard Screenshot
- Coursera Certificate

Objective

The main objective of this project is to demonstrate practical skills in SQL, Excel, data analysis, and data visualization.
